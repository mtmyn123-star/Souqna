سوقنا — نسخة تصميم أولية
=========================

هذه نسخة Frontend تعمل بدون قاعدة بيانات وبدون بوابة دفع، ومناسبة كبداية للمشروع.

طريقة التشغيل:
1) افتح المجلد marketplace-site داخل Visual Studio Code.
2) افتح index.html.
3) أسهل طريقة: ثبّت إضافة Live Server في VS Code ثم اضغط بزر الفأرة الأيمن على index.html واختر Open with Live Server.
4) أو افتح index.html مباشرة في المتصفح.

الصفحات الموجودة:
- الرئيسية
- المنتجات والبحث والأقسام
- السلة
- لوحة البائع
- لوحة الإدارة
- نظام تجريبي لطلب سحب الأرباح
- حساب عمولة المنصة

ملاحظة:
هذه نسخة واجهة أولية. الخطوة التالية في التطوير هي ربطها بقاعدة بيانات وتسجيل دخول حقيقي ونظام الطلبات ومخزون المنتجات وتدقيق المدفوعات والتحويلات.
